# Minha-Landing-Page
#  Ivanir Mannes - Landing Page Profissional

Página web profissional para **Ivanir Mannes**, especialista em Constelação Familiar, Reiki e Barras de Access.

Sobre o Projeto

Uma landing page moderna e responsiva que apresenta os serviços de terapia integrativa, com foco em acolhimento, escuta sensível e transformação pessoal.

 Funcionalidades

- Menu Mobile Responsivo - Navegação fluida em todos os dispositivos
- Scroll Suave - Navegação entre seções com transição elegante
- FAQ Acordeão - Perguntas frequentes com abertura/fechamento
- Animações de Entrada - Elementos aparecem ao scroll (IntersectionObserver)
- Layout 2x2 - Cards de serviços bem organizados
- Integração WhatsApp - Links diretos para agendamento
- Mapa Interativo - Localização no Google Maps
- Design Responsivo - Otimizado para desktop, tablet e mobile

 Tecnologias

- HTML5 - Semântico e acessível
- CSS3 - Grid, Flexbox, Variáveis CSS
- JavaScript  - Sem dependências externas
 - ntersectionObserver API - Animações otimizadas
